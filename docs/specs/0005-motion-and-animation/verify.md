## Setup

- Build and serve production next to the dev server: `pnpm build`, then `pnpm exec next start -p 3100`. Dev output lives in `.next/dev`, so the build doesn't disturb `pnpm dev`.
- Run the checks by hand in the browser DevTools. The project has no browser test tooling.
- To count view transitions, paste a snippet in the console that wraps `document.startViewTransition` and increments `window.__vt`.
